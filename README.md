# Course Notes Tutor (Obsidian plugin)

1. **Photo to notes**: photograph your lecture notes. A vision-capable LLM transcribes and organizes them into Markdown and writes the result into the matching course folder.
2. **Material check**: checks whether the professor's notes for that day have been uploaded, and reminds you if they haven't.
3. **Gap-finding chat**: your notes, the Course Note and the professor's notes (PDFs are sent as page images) go to the model together. The model then asks you one question at a time to find gaps in understanding and things you didn't write down. At the end it writes a report back into that day's note.

> The plugin's interface and prompts are currently in Chinese.

## Platforms

The target platforms are macOS, iOS and iPadOS. Platform-specific code lives in `src/platform.ts`.

| | iPhone | iPad | macOS |
|---|---|---|---|
| Take photo | Opens the camera | Opens the camera | — |
| Photos / Files (including PDF) | ✓ | ✓ | ✓ |
| Pick from vault (photos synced from another device, files saved via the iOS share sheet) | ✓ | ✓ | ✓ |
| Drag and drop / paste | Paste | Drag and drop (Split View) + paste | Drag and drop + paste |
| HEIC photos | Decoded by the system | Decoded by the system | Converted with the built-in `sips` |
| Review panel | Tab in the main area | Right sidebar | Right sidebar |

Note capture also accepts PDFs, such as handwritten notes exported from GoodNotes or Notability, or documents scanned in the Files app. Each PDF page is treated as one photo.

API keys: on Obsidian 1.11.4 and later, keys are kept in Obsidian's secret storage and are not written to the plugin's `data.json`. Earlier versions fall back to plain text in `data.json`.

## Vault layout (defaults, configurable in settings)

```
Courses/                         ← courses root
  Linear Algebra/                ← each subfolder is one course
    课堂笔记/2026-10-05 Linear Algebra.md   ← generated by the plugin
    Course Note.md               ← Course Note (a file or a folder)
    教授笔记/Lecture 2026-10-05.pdf          ← professor's notes you upload
    attachments/                 ← compressed note photos
```

Professor's notes count as "that day's" notes in either of these cases:

- the file name contains the date (`2026-10-05`, `20261005`, `10月5日`, `10.5` and similar formats all work);
- the file was added to the vault on that day.

If neither applies, the plugin reminds you to upload them. You can also tick files by hand in the review panel.

## Timetable

Put an ICS/webcal subscription link in settings. The plugin expands weekly recurring classes and handles cancelled classes (EXDATE) and rescheduled classes (RECURRENCE-ID). That day's events are listed for you to pick from, but **the course selected in the dropdown is what counts**. Events that don't match a course folder are shown greyed out and can't be selected. When the timetable uses different names from your folders, map them under "Course aliases":

```
Linear Algebra = MATH 221, 线性代数
```

## Models

- **Anthropic Claude**: defaults to `claude-opus-5-5` with effort `high`. Server-side refusal fallback (`fallbacks: "default"`) is on by default. The gap-finding chat caches the course materials, which lowers the cost of multi-turn conversations.
- **OpenAI-compatible APIs**: enter the base URL, key and model ID. The model must accept image input.

All requests go through Obsidian's `requestUrl`, so CORS restrictions don't apply.

## Development

```bash
npm install
npm run dev     # watch build
npm run build   # type check + production build
npm test        # unit tests for pure logic (dates, course matching, ICS expansion)
```

To install into a vault, copy `main.js`, `manifest.json` and `styles.css` to `<vault>/.obsidian/plugins/obsidian-learn/`, then enable the plugin under Community plugins.
